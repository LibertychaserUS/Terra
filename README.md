# Terra

Terra is an experimental terminal-native Agent OS interface.

It aims to provide a structured workspace for interacting with AI agents, tasks, memory, tools, and project-level execution flows.

> Status: early prototype / active development.

## Vision

Terra is not just a chat interface.  
It is designed as a local-first control surface for agentic workflows.

The long-term goal is to build a terminal-native workbench where users can:

- define goals
- run agent tasks
- inspect execution traces
- manage project context
- connect tools, memory, and skills
- coordinate multiple AI agents through a structured interface

## Current Prototype

The current version focuses on the basic TUI experience:

- chat-style terminal interface
- goal/input mode
- status bar
- input history
- local interactive loop

More components will be added progressively.

## Design Principles

- Local-first
- Terminal-native
- Agent-oriented
- Inspectable execution
- Structured task flow
- Minimal but extensible interface
